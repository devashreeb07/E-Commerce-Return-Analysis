# 📊 E-Commerce Return Analysis

An end-to-end data analytics project that analyzes e-commerce order returns to identify return patterns, high-risk product categories, customer behavior, financial impact, and environmental impact.

The project uses **Python, SQL, and Power BI** to transform raw e-commerce transaction data into actionable business insights.



## 📌 Project Overview

Product returns are a major challenge for e-commerce businesses because they can increase operational costs, reduce profitability, and create additional packaging and environmental waste.

This project analyzes **5,000 e-commerce transactions** to understand:

- Overall return rate
- Product categories with high return rates
- Major reasons for product returns
- Products and locations with higher return rates
- Relationship between discounts and returns
- Order value and return patterns
- Payment and shipping method patterns
- Financial impact of returns
- Environmental impact of returned orders

An interactive **Power BI dashboard** was developed to present the findings clearly and support business decision-making.

---

## 🎯 Business Problem

E-commerce companies need to understand why customers return products and which factors are associated with higher return rates.

The main business questions addressed in this project are:

1. What is the overall return rate?
2. Which product categories have the highest return rates?
3. What are the most common reasons for returns?
4. Which products have unusually high return rates?
5. Which locations show higher return rates?
6. Does a higher discount appear to be associated with more returns?
7. How do payment and shipping methods relate to returns?
8. What is the financial impact of product returns?
9. What environmental impact is associated with returns?

---

## 🎯 Project Objectives

- Clean and prepare the e-commerce dataset.
- Perform exploratory data analysis using Python.
- Analyze return patterns using SQL.
- Calculate important business KPIs.
- Build an interactive Power BI dashboard.
- Identify high-risk categories, products, and locations.
- Analyze financial and environmental impacts.
- Provide data-driven business recommendations.
